# Step 1: Brainstorm

## Before executing
Read: references/genre-rules.md

## Process
1. Determine setting — Ask user OR select from: haomon, trungsinh, hocduong, honnhan-giadinh, congso, lyki-thriller, ngontinh
2. Read the matching settings/*.md file for motifs and conflict templates
3. Select 1-2 motifs from the setting file
4. Define Hook — protagonist ALREADY in crisis (not building up). Specific concrete injustice.
5. Define Core Conflict — what must be overcome
6. Define Evidence Path — what physical evidence will be collected (see references/evidence-arsenal.md)

## Output format
```
## Concept Brief
**Setting**: [name]
**Motifs**: [1-2 from setting file]
**Hook**: [1-2 sentences — the opening crisis]
**Core conflict**: [what must be overcome]
**Evidence path**: [3-5 evidence types]
**Antagonist's fatal flaw**: [behavior that creates evidence against them]
**Target word count**: [5000-12000]
```
