# Step 2: Outline

## Before executing
Read: references/sang-diem-formulas.md + references/golden-patterns.md

## Process
1. Map 4 phases using templates/outline-template.md
2. Place 4-5 satisfaction peaks (select from sang-diem-formulas.md):
   - Hook: 0-1 peaks (F1/F2)
   - Rising: 2 peaks (F3-F5)
   - Climax: 2 peaks (F6-F11)
   - Resolution: 1 peak (always F12)
3. Map evidence revelation order — weakest to strongest
4. Select 2-3 golden patterns from golden-patterns.md
5. Define cold closing line (<=15 words)
6. Calculate word budget: Hook 15% / Rising 45% / Climax 25% / Resolution 15%
