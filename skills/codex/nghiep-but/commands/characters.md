# Step 3: Characters

## Before executing
Read: references/archetypes.md + references/dialogue-playbook.md

## Process
1. Select archetypes for each role
2. Fill templates/character-sheet.md for each character:
   - Sino-Vietnamese name (2-3 syllables)
   - Archetype + variation
   - 2-3 signature dialogue lines
   - Arc across story
   - Relationship to evidence
3. Dialogue differentiation check: read all signature lines together — must be distinguishable without names
   - Protagonist: short, question-heavy, calm
   - Antagonist: commanding -> desperate (sentences get longer)
   - Bach nguyet quang: soft public / cold private

## Output: Character sheets per templates/character-sheet.md
