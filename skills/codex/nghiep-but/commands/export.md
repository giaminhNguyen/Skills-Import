# Step 6: Export

## Rules
1. Save the final story to workspace/<slug>/story.md
2. Single continuous text — NO chapter headers, NO section numbers, NO dividers
3. NO metadata, NO author notes, NO "THE END"
4. Reads as one unbroken narrative; final line IS the cold closing line
5. Verify word count 5,000-12,000

## Silent output
Do NOT print the story to chat. After saving, print only the completion report
(see SKILL.md "Completion report format"). Then, if the story was requested as
audio-bound, offer Step 7:
```
Muon tao ban doc cho TTS khong? (Step 7)
```
