# Setting: Hao Mon (Wealthy Family)

Core conflict: Power struggles in ultra-wealthy families — inheritance, identity, control.

Motifs (select 1-2):
- M1 Real vs Fake Heiress (that-gia thien kim): babies swapped, real heiress returns treated coldly, fake schemes. Evidence: DNA, birth records, hospital footage.
- M2 Inheritance Rules: strict rules (birth order, male heir). One branch blocks others. Protagonist works around rules legally, reveals children already born.
- M3 Donation Power Play: family uses donations to control institutions. Protagonist exposes corruption. Evidence: contract terms, kickback records, audit.

Characters: Patriarch (rules), protector (tong tai, after 60%), scheming first wife, weak husband.
Evidence: DNA/paternity, corporate audit, property docs, donation contracts with hidden terms.
