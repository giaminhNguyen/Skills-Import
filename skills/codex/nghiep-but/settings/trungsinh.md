# Setting: Trung Sinh (Rebirth)

Core conflict: Protagonist died unjustly in previous life, reborn to moment before disaster. Reverse fate with foreknowledge.

Motifs:
- M1 Reversed Hunter-Prey: previous life prey -> this life knows every enemy move. Follow SAME path initially, different choices at critical moments.
- M2 Evidence Pre-collection: know WHERE/WHEN evidence appears. Install cameras, record BEFORE events. Antagonist confused by "impossible" preparedness.
- M3 The Echo: antagonist repeats exact same words/actions. Each echo = brief flashback (1-2 sentences). Reaction: cold confirmation, not pain.

Rules: NEVER dump previous-life backstory in one block. Reveal through echoes. Foreknowledge has LIMITS (know events, not every detail). Previous death revealed in fragments, full picture at climax only.
