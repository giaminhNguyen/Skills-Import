# Setting: Cong So (Workplace)

Core conflict: Colleague exploits protagonist's resources, escalates when confronted, destroyed by evidence trail.

Motifs:
- M1 Freeloader Escalation: takes snacks -> refuses pay -> mocking spreadsheet -> fake group charging others using protagonist's name -> buys expired food labeled with protagonist's name. Evidence: receipts, group chat screenshots, payment records, warehouse invoice for expired goods.
- M2 Review Extortion: assistant uses negative reviews to extort store owners.
- M3 Manager Complicity: manager sides with perpetrator, asks protagonist to apologize. Protagonist escalates to HR. Manager also faces consequences.

Key pattern — Paper Trail: documentation over dramatic confrontation. Every interaction is evidence. Final confrontation in HR/meeting room, not public.
