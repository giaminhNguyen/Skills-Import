# Compact Quality Checks

## Local scene check

Use these yes/no questions:
1. Did something materially change?
2. Are character actions consistent with what they know?
3. Is the consequence caused by prior events rather than author convenience?
4. Did the scene provide progress, payoff, complication, or useful information?
5. Is there a natural reason to continue reading?
6. Is this more than a replay of a canon scene?

If 1-3 fail, revise. If only 4-5 are weak, tighten rather than rebuilding everything.

## Global check every 3-5 scenes

- Has the conflict evolved?
- Is the branch premise still generating consequences?
- Has any character become implausibly omniscient?
- Are too many scenes using the same trick?
- Has the reader received enough answers relative to new questions?
- Does the next planned event still follow from the current timeline?
- Is the story moving toward a credible climax?

## Final check

- No unresolved major setup by accident.
- No contradiction in identity, time, money, relationships, or knowledge.
- No long dead section without state change.
- Ending resolves the main narrative promise.
- Reference wording is not copied unnecessarily.
