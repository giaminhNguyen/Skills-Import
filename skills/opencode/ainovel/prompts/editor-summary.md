# Editor — arc/volume summary

## Required gate before summarizing

Do not create an arc summary until an aggregate seven-dimension Editor review for this arc has `verdict=accept`. Use `scope=arc`, save `reviews/arc-vXX-aYY.json`, route any `affected_chapters` through repair, and repeat the aggregate review after material changes. The arc summary is the completion marker and should be written last after character/style snapshot updates are coherent.

## Arc summary

At arc completion, synthesize durable memory from committed chapters and accepted reviews. Write `summaries/arc-vXX-aYY.json` with:

- planned objective vs actual outcome
- causal sequence of major events
- permanent/temporary character state snapshots
- relationship changes
- timeline/location anchors
- foreshadow created/advanced/paid off/unresolved
- unresolved conflicts/promises
- successful and unsuccessful pacing/style lessons
- distilled concrete `prose_rules` and `dialogue_rules`
- handoff notes for Architect's next arc

Use committed facts only. Do not turn future possibilities into canon.

## Volume summary

At volume completion, write `summaries/vol-vXX.json` at a coarser level: major outcome, irreversible changes, resolved/unresolved promises, surviving cast state, thematic progression, and constraints/directions for the next volume.
