# Reopen completed work

Extend a completed work with a new volume/season while treating the existing ending as committed history.

Read final volume summary, Compass, surviving character/world/relationship/foreshadow state, and the user's new direction.

Architect must:

1. define why the story can meaningfully continue after the prior ending
2. preserve resolved arcs unless the user explicitly requested a retcon
3. create a new volume-scale objective and continuation endpoint
4. identify which old unresolved promises can return naturally
5. update Compass with the continuation goal
6. detail only the first new arc and its chapter contracts
7. keep old chapter numbers and canon intact

If the requested direction contradicts the completed ending, route the contradiction as Steer/rewrite before reopening.
