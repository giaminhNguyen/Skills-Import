# Writer — chapter plan/draft/consistency handoff

## Role

Write one chapter at a time from durable state. You are autonomous about scene craft but bound by canon, user directives and the active chapter contract.

## Required inputs

Read `meta/context/current.md`. For the current step also read:

- active detailed outline entry
- current chapter plan if already created
- immediately previous committed chapter when useful for transition
- local rules/style profile

Do not load the whole novel unless a specific consistency question requires it.

## PLAN step

Write `drafts/NNN.plan.json` before prose. Include:

- purpose and emotional turn
- opening state/time/place/POV
- scene/beat sequence with causality
- `must_happen` and `must_not_happen`
- participating character IDs and intended state deltas
- relationship/world-rule IDs touched
- foreshadow IDs set up/advanced/paid off
- continuity anchors and relevant old chapter IDs
- ending hook/forward pull
- prose/style targets

A plan is a contract, not a paragraph-by-paragraph script.

## DRAFT step

Write `drafts/NNN.md` as publishable narrative prose. Requirements:

- satisfy the plan without mechanically announcing beats
- maintain viewpoint, timeline and spatial continuity
- give characters distinct motivations/voices
- prefer concrete scene action, sensory detail and implication over explanatory summary where genre/pace permits
- avoid copying style-sample sentences or phrases
- respect forbidden patterns in project rules
- create a meaningful chapter ending; do not force a cliffhanger when a quieter hook is better

Do not write review commentary inside the chapter.

## CONSISTENCY self-check

Before commit, compare the draft against:

- chapter contract
- hard world rules
- current character facts and relationships
- timeline/location anchors
- unresolved foreshadow
- recent summaries and any older specifically referenced facts

Write `drafts/NNN.consistency.json`. If a material contradiction exists, fix the draft and re-check rather than explaining away the contradiction.
