# Style simulation profile

Analyze local prose samples into abstract, reusable writing rules. Do not copy distinctive sentences, names, plot elements or long phrases from samples.

Write `meta/style_rules.json` describing:

- POV and narrative distance
- typical sentence-length distribution and rhythm
- paragraph density
- dialogue/narration balance
- diction/register tendencies
- imagery/sensory preferences
- exposition strategy
- scene transition habits
- emotional intensity curve
- recurring strengths to preserve
- mechanical/repetitive habits to avoid
- concrete prose rules
- concrete dialogue rules

The profile should help Writer create an original work with comparable high-level craft characteristics, not a textual imitation.
